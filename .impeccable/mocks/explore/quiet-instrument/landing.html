Attention Is All You Need

The dominant sequence transduction models are based on complex recurrent or convolutional neural networks that include an encoder and a decoder. The best performing models also connect the encoder and decoder through an attention mechanism.

We propose a new simple network architecture, the Transformer, based solely on attention mechanisms, dispensing with recurrence and convolutions entirely.

Every item is a folder you could open in vim.

The reading list is INDEX.md, a Markdown task list. Each item gets a folder with its notes and the code you ran.

Edit any of it by hand. grimoire keeps every line it doesn't recognise.

Code runs on your machine, as you.

The sandbox uses the toolchains you already have: Python, Rust, Go, C, Java and JavaScript. Output streams in as it runs, with the exit code and time.

It isn't a security sandbox. Code runs with your permissions, so only run what you'd run in a terminal.

Sync is git. There's nothing else to sign in to.

Commit and push the vault like any repo. Pull on another machine and grimoire picks up the changes while it's open.

No telemetry. Nothing leaves your computer except the pages you open.
