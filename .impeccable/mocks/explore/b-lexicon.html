i. async fn returns a future

  1. async fn doesn't run anything when called. It returns a value that implements Future, and nothing happens until something polls it.
  2. .await is where the current future yields if the inner one is Pending.
  3. Futures start running as soon as they're created. They don't; see 1.

ii. Lifetimes and async

An async fn that borrows its arguments returns a future that borrows them too, so the future can't outlive them.

Fix from the chapter: move the borrow into an async move block so the future owns what it needs.
