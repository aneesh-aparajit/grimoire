async/.await

async/.await are special pieces of Rust syntax that make it possible to yield control of the current thread rather than blocking, allowing other code to make progress while waiting on an operation to complete.

There are two main ways to use async: async fn and async blocks. Each returns a value that implements the Future trait.

// `foo()` returns a type that implements `Future<Output = u8>`.
async fn foo() -> u8 { 5 }

Async bodies and other futures are lazy: they do nothing until they are run. The most common way to run a Future is to .await it.

async lifetimes

Unlike traditional functions, async fns which take references or other non-'static arguments return a Future which is bounded by the lifetime of the arguments.

## async fn returns a future

  • async fn doesn't run anything when called. It returns a value that implements Future, and nothing happens until something polls it.
  • .await is where the current future yields if the inner one is Pending.
  • Futures start running as soon as they're created. They don't; see above.

## Lifetimes and async

An async fn that borrows its arguments returns a future that borrows them too, so the future can't outlive them.
